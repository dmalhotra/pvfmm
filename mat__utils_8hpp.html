template<class T>
void pvfmm::MatrixTranspose ( size_t in_dim1,
size_t in_dim2,
sctl::ConstIterator< T > in,
sctl::Iterator< T > out )

Transpose the in_dim1 x in_dim2 row-major matrix at in into out (which receives in_dim2 x in_dim1). If in==out, the transpose is done in place, staging the input through per-thread scratch storage; otherwise the two ranges must not overlap.
