Detailed Description

Owns the device-side mirror of one host buffer: the page-locked registration of the host range (cudaHostRegister) and the device allocation. This lifecycle state previously lived inside Vector/Matrix as the dev member and the AllocDevice/FreeDevice/Device2Host methods.

Contract: while bound, the host buffer must not be freed, resized, or reallocated — call Free() first. Releasing the pinned registration requires the host pages to still be mapped, so a stale binding cannot be released after the host buffer is gone; AllocDevice asserts if called with a different host range while still bound.
