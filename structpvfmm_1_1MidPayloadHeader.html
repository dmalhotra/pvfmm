Detailed Description

Wire record header pairing a MortonId with the byte length of the payload that follows. Used to frame packed nodes / multipole data in tree exchange messages. Records may land at non-8-byte offsets in a stream (payload lengths are Real_t multiples), so read/write with memcpy.
